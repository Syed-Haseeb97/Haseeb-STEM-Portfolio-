## 💻 Running Locally

```bash
git clone https://github.com/Syed-Haseeb97/Haseeb-STEM-Portfolio-.git
cd Haseeb-STEM-Portfolio-
npm install
npm run dev
```

Build:

```bash
npm run build
```
